Notes (optional follow-ups, no change required to approve):

Worth adding "or a private-use scheme" when the docs are next touched; trust on first use stays https only, as the README says.
- "registrations idle for more than a day" is really "registrations over a day old that hold no code or token".
- Not documented, and fine to leave (T13 review notes): the CSP `form-action` also lists the client's redirect origin (needs a ledger decision line and a real-browser check in T15); the server-wide 200 pending cap with unrate-limited `/authorize`.
