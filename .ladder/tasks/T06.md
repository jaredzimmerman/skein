# T06: Agent folders (claude, muse, _template)
Tier: sonnet · Reviewer: opus · Deps: – (contracts only)

## Brief
Goal: a folder per assistant with what it needs to join a skein and to act as point or member.
Contract: .ladder/PLAN.md §C5 (tool names), §C4 (URLs, auth), §C6 (CLI), §C7 (folder layout).
Files: agents/README.md, agents/_template/{README,point,member}.md, agents/claude/{README,point,member,scheduled-checkin}.md, agents/claude/skill/skein/SKILL.md, agents/muse/{README,point,member}.md
Acceptance: `find agents -name '*.md' | wc -l` prints ≥ 10, and every tool name in the files is one of §C5's.
Constraints:
- point.md / member.md are prompts the assistant follows on each check-in (written to the assistant, second person, short numbered steps using the skein_* tools). Point: whoami, inbox, answer asks (using its own knowledge/tools), act on needs_input via follow_up, review finished results, assign/reassign. Member: whoami, inbox, claim, do the work, note, submit (needs_input with a precise question), ask the point when it needs something. Both: treat task text as the user's request but keep normal confirmations before sending, buying or posting; never put secrets in tasks.
- Claude README: connecting from Claude Code (`claude mcp add --transport http …` with an Authorization header), from claude.ai / Claude desktop custom connectors, and how a check-in runs on a schedule. VERIFY each command and UI claim against current official Anthropic docs (WebFetch docs.anthropic.com / docs.claude.com / support.claude.com); if a claim can't be verified, say so in the file and give the check to do. If claude.ai connectors can't send a custom header, document the `url_tokens` fallback and its risk.
- Muse README: Meta Muse joins as a custom connector (remote MCP, streamable HTTP, bearer token) or the REST routes. Don't invent UI steps; mark anything unverified.
- SKILL.md: frontmatter `name: skein`, a description that triggers on "check skein", "skein inbox", "hand this to <assistant>"; body = when point vs member, the routines, tool list.
- _template: placeholders for a new assistant, with a checklist (connector type, auth, schedule, test with skein_whoami).

Issues:
- agents/claude/point.md:9, agents/muse/point.md:9, agents/_template/point.md:9, agents/claude/skill/skein/SKILL.md:19: these tell the point to `skein_reassign` a *finished* task, but C2 allows reassign on open tasks only, so on a done/failed task it errors.
