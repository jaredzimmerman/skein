Notes for T03/T04 (interpretations where §C2 is silent):
- API: `Store(path)` creates the file, schema, WAL and user_version 1 on construction (`skein init` = `Store(path)`). `Skein(store_or_path, clock=time.time)`. Writes run in `store.tx()` (BEGIN IMMEDIATE, one connection per operation).
- `list_tasks`, `list_asks`, `members`, `list_members` return lists, not dicts. Wrap them for MCP structured output if needed.
- `SkeinError.to_dict()` → `{"error", "code"}`.
- Error codes: unknown assign/reassign target → not_found; a disabled target or the point → conflict; unknown/disabled caller → forbidden; the point claiming/submitting someone else's task → forbidden.
- `submit` on a needs_input task → conflict (it reopens only via follow_up). Submit from queued auto-sets `claimed`. A re-submit inside the amend window resets `finished`, so the window restarts.
- Truncation cuts to the exact limit, with "…" as the last character. Titles have whitespace collapsed. `list_tasks(status=)` also accepts `open`. In `list_asks`, an empty status means `open`.
- `set_point` → `{point, previous}`; `set_disabled` → `{name, disabled}`. A disabled member can still be the point (it just can't authenticate).
